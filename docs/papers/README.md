# Academic papers

Acquired PDFs of the papers indexed in [`../bibliography/05-papers.md`](../bibliography/05-papers.md) (and the `05 #n` cross-references in the thematic files [08](../bibliography/08-voice-metrology-on-the-wrist.md), [09](../bibliography/09-visual-feedback-for-singing.md), [10](../bibliography/10-datasets-and-ground-truth.md)). Filed **by topic, not by author**, so a reader exploring a subdomain finds everything in one place — and the topic directory is the section heading of the paper's entry in file 05, so index and library never disagree about where something goes.

The thirteen directories exist with `.gitkeep` placeholders; replace the placeholder with the first PDF filed. Adding a topic means adding a section to file 05 **and** a directory here, in the same commit.

## Filing convention

- Filename pattern: `<firstauthor><year>_<short-title>.pdf` — for example `heinzel2002_dft-spectrum-estimation.pdf`, `omori1996_singing-power-ratio.pdf`, `svec2010_microphone-guidelines.pdf`, `nunez2018_cividis.pdf`.
- Lowercase only, hyphens inside the short title, no spaces; transliterate diacritics (`svec`, `porschmann`, `muller`).
- Same first author and year → append `a`, `b` (`svec2010a_…`, `prame1994_…` / `prame1997_…` need no suffix).
- Save the published version when accessible; otherwise the arXiv/author preprint with `_arxiv` or `_preprint` appended. Image-only scans (e.g. Sundberg 1974) get OCR'd via the sidecar tooling.
- Keep the original PDF unmodified. Hand-written notes go alongside as `<original>_notes.md` (tracked); machine extractions are generated by `python3 -m doc_ocr extract` as `<original>.ocr.md` (gitignored, disposable) — see [`../OCR/README.md`](../OCR/README.md).
- **Directory-README exception (swarm parity).** `by-topic/` is a pure grouping level and deliberately carries neither a `README.md` nor a `.gitkeep`: this file is the README for the whole `papers/` tree, and the thirteen topic leaves keep the path alive in git. This mirrors `swarm/docs/papers/by-topic/` exactly and is the one place where the "every directory has a README" rule is satisfied by the parent. Do not add a `by-topic/README.md` later — it would split the layout table above into two places that drift.

## How this couples to the bibliography

Each entry in [`../bibliography/05-papers.md`](../bibliography/05-papers.md) carries a DOI, arXiv ID or stable URL; the same identifier should appear in the filed PDF's metadata or first page so `grep` works both ways. When a paper lands here, add a `📥 Filed locally: ../papers/by-topic/<topic>/<file>` blockquote to its entry in file 05 (and to the cross-referencing row in 08/09/10 while those still carry local letters). Gaps — paywalls, CDN blocks, browser-only hosts — are ledgered in [`../bibliography/acquisition-status.md`](../bibliography/acquisition-status.md).
