# Proposal

Research proposal for Super Spectral (English; single-language rule).

- [`01-super-spectral-proposal.md`](01-super-spectral-proposal.md) — the **binding** project statement. Skeleton filed in roadmap phase D0/D2 with the provisional research question, five objectives, technical approach, validation plan, contributions, 16-week timeline, limitations and a References section whose citation addresses are resolved in [D2](../roadmap/documentation-roadmap.md). Every `(prov.)` and `TBD` in it is tracked by the roadmap's routing table; the research question is frozen (tag removed) only in the D2 closing commit.
- [`research-statement.md`](research-statement.md) — reusable one-page research-interest statement derived from §1/§2/§5, in swarm's five-paragraph shape. Application-facing, with a per-programme swap zone; **draft**, not a binding document.

The proposal sets the binding constraints for this repo: research question (§1), objectives (§2), technical approach (§3), validation plan (§4), and the 16-week timeline (§6). Treat any deviation as worthy of an ADR in [`../adr/`](../adr/README.md). The acceptance-metrics table is **not** duplicated here — §4 links to [`../validation/README.md`](../validation/README.md), which is the single source.

Not copied from swarm: the `statements/` tree of per-programme application variants. It is created only if and when an application is being written.
