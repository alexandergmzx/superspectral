# ESP-IDF pitfall catalogue — T-Watch S3, v6.0.x, this host

Deduplicated from the 2026-08-20 environment research (six agent reports) and **corrected per the critic's review** (devenv_critic §A1–A8: wrong symptom in B18, stale brownout citation, mis-sourced esptool constraint, in-tree panel list, over-broad `esp_lcd` porting note, the `newlib → esp_libc` rename, host drift, and — throughout — symbol/string citations instead of line numbers, which rot between v6.0.2 and v6.1). File paths are relative to the ESP-IDF tree; every `CONFIG_*` symbol named here was grepped in the v6.0.1 tree on this host on 2026-08-20.

Row IDs are stable and are cited from [setup.md](setup.md), the runbooks, ADR 0001/0014/0015 and the pre-commit hooks. New rows are appended, never renumbered. Sections: [A](#a-host-toolchain-shell) host · [B](#b-build-system-and-configuration) build system · [C](#c-flash-psram-power) flash/PSRAM/power · [D](#d-memory-placement-and-runtime) memory/runtime · [E](#e-usb-serial-jtag-flashing-recovery) USB/flash/recovery · [F](#f-irreversible-efuse-operations) eFuse · [G](#g-testing-ci-emulation) testing/CI · [H](#h-ecosystem-and-expectations) ecosystem.
